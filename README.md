#  Device Tree for MEIZU 20 Pro (`m2391`)

## Build

```sh
source build/envsetup.sh
source vendor/lineage/vars/aosp_target_release
lunch lineage_m2391 "$aosp_target_release" userdebug
mka bacon
```
